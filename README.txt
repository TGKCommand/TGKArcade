TGK Daily Race - GitHub Pages site
==================================
index.html   the game (single file; three.js loads from cdnjs)
CNAME        tells GitHub Pages to serve this site at race.tgkmotorsport.com
.nojekyll    tells GitHub not to run Jekyll on it

Upload all three to the ROOT of the repo (GitHub > Add file > Upload files). Do not put the server/ folder in this repo.
